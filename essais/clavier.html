Où passe la touche ?

Cette page ne contient que le code ci-dessous : ni le module, ni aucune bibliothèque. Si une touche s'y perd déjà, le module n'y est pour rien — la cause est dans le navigateur, une extension, ou le clavier.

1. Tapez ici

Tapez l'alphabet en minuscules, puis en majuscules. Prenez votre temps.

2. Bilan

Tapez quelque chose, puis cliquez sur « Voir le bilan ».

3. Le détail, touche par touche

Une ligne par touche pressée. annulé veut dire que quelque chose a bloqué la touche ; texte inséré dit si un caractère est réellement arrivé dans la zone.
