Publier — 04 / 05

Publier, c'est un bouton.

Le client clique, son site est à jour — sur un hébergement PHP comme sur Vercel. Le disque de Vercel est en lecture seule après déploiement : « écrire un fichier » y veut donc dire « committer dans le dépôt », ce que fait une fonction du module, et le site se redéploie tout seul.

Les images, elles, vont dans Firebase Storage : elles ne touchent jamais le disque de l'hébergeur, quel qu'il soit. Personne n'a de fichier à télécharger ni à déposer à la main.

Et si le module est retiré un jour, le site garde tout : à chaque publication, le fichier HTML est réécrit avec le contenu à l'intérieur. Ce n'est pas une promesse, c'est la façon dont le module fonctionne — il n'y a rien d'autre à faire pour que ça reste vrai.
